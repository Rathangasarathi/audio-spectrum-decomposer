§ 1 Problem Statement

Meriam & Kraige Problem 4/22 — A loaded Pratt truss has five top-chord nodes A, B, C, D, E spaced at equal horizontal distance d, and three bottom-chord nodes H, G, F hanging at depth d below the top chord.

Applied loads act downward: L/2 at nodes A and E, and L at nodes B, C, D. Support conditions: a pin at A and a 45°-inclined roller at E.

The student must determine the forces in all 13 members of the truss, classifying each as Tension (T), Compression (C), or zero-force.

Core Concept
This problem applies the Method of Joints — at each pin joint, the two equilibrium equations (ΣFx = 0 and ΣFy = 0) are used to find unknown member forces. Joints are solved in a sequence beginning with those having only two unknowns. Member CG supports the full load at joint C directly.

§ 4 Global Equilibrium — Reactions

Moment about A (ΣMA = 0)

Taking clockwise moments as positive, with the roller reaction E perpendicular to the 45° surface (i.e., at 45° to horizontal, components E·cos45° leftward and E·sin45° upward):

−L·d − L·2d − L·3d − (L/2)·4d + E·(1/√2)·4d = 0
−8Ld + 2√2·E·d = 0   ⟹   E = 2√2·L

Force Equilibrium

ΣFx = 0 :   Ax = E·cos45° = 2L
ΣFy = 0 :   Ay + E·sin45° − 4L = 0  ⟹  Ay = 2L
Symmetry Check
By the symmetry of the loading (L/2 at both ends, L at all interior nodes) and geometry, Ay = E·sin45° = 2L — the truss is loaded symmetrically, confirming equal vertical reactions.

§ 5 Method of Joints — Derivation

Joint A → Members AH (T) and AB (C)

External at A: Ax = 2L (→), Ay = 2L (↑), applied load = L/2 (↓). Members: AB (horizontal →) and AH (diagonal 45° down-right).

ΣFy = 0: 2L − L/2 − AH / √2 = 0  ⟹  AH = 3√2L/2 (T)
ΣFx = 0: 2L + AH/√2 − AB = 0  ⟹  AB = 7L/2 (C)

Joint E → Members FE (T) and DE (C)

By symmetry with joint A: FE = 3√2L/2 (T) and DE = 7L/2 (C).

Joint H → Members BH (C) and HG (T)

Known: AH = 3√2L/2 (T). Directions from H: to A = (−1/√2, +1/√2), to B = (0,+1), to G = (+1,0).

ΣFy = 0: AH/√2 + BH = 0  ⟹  BH = 3L/2 (C)
ΣFx = 0: −AH/√2 + HG = 0  ⟹  HG = 3L/2 (T)

§ 6 Joints B, C, and G

Joint B → Members BG (T) and BC (C)

Known: AB = 7L/2 (C), BH = 3L/2 (C).

ΣFy = 0: BH − L − BG/√2 = 0  ⟹  BG = L√2/2 (T)
ΣFx = 0: AB + BC + BG/√2 = 0  ⟹  BC = 4L (C)

Joint C → Members CG (C) and CD (C)

Known: BC = 4L (C). No diagonals at C.

ΣFy = 0: −L − CG = 0  ⟹  CG = L (C)
ΣFx = 0: BC + CD = 0  ⟹  CD = 4L (C)
Verification at Joint G
At joint G, horizontal equilibrium: −HG − BG/√2 + DG/√2 + GF = 0. Vertical equilibrium: −CG + BG/√2 + DG/√2 = 0 ⟹ −L + L/2 + L/2 = 0 ✓. The compression of CG perfectly balances the upward pull of diagonals BG and DG.

§ 8 Sample Calculation (L = 10 000 N, d = 1 000 mm)

Step 1 — Global equilibrium
  ΣM_A = 0:  −Ld − L(2d) − L(3d) − (L/2)(4d) + E·(1/√2)·4d = 0
             −8Ld + 2√2·E·d = 0
             E = 2√2 × 10000 = 28284.3 N
  A_x = E·cos45° = 20000 N
  A_y = 4L − E·sin45° = 20000 N

Step 2 — Joint A
  ΣFy: 20000 − 5000 − AH/√2 = 0
       AH = 15000 × √2 = 21213.2 N  (T)
  ΣFx: 20000 + 21213.2/√2 − AB = 0
       AB = 20000 + 15000 = 35000 N  (C)

Step 3 — Joint H
  ΣFy: 15000 + BH = 0  →  BH = 15000 N (C)
  ΣFx: −15000 + HG = 0 →  HG = 15000 N (T)

Step 4 — Joint B
  ΣFy: 15000 − 10000 − BG/√2 = 0  →  BG = 7071.1 N (T)
  ΣFx: 35000 + BC + 5000 = 0      →  BC = 40000 N (C)

Step 5 — Joint C
  ΣFy: −10000 − CG = 0  →  CG = 10000 N (C)
  ΣFx: 40000 + CD = 0   →  CD = 40000 N (C)

Steps 6,7,8 — By symmetry (D, F, E) give DF, GF, DG, FE, DE.

§ 9 Application User Flow

The interactive solver follows a five-step workflow:

① Load Page
→
② Set d & L
→
③ Diagram Updates
→
④ Compute
→
⑤ All 13 Members
  • Load Page: The solver loads with default values (d = 1 000 mm, L = 10 000 N) and renders the live canvas truss diagram with grid, dimension lines, and load arrows.
  • Set d & L: Two input fields allow the student to parametrically change the panel spacing and applied load. Symbolic inputs (e.g., "L") are supported.
  • Diagram Updates: The HTML5 Canvas redraws in real time as values change — nodes reposition, members rescale, load arrows update.
  • Compute: Clicking "Compute Solution" runs the full method-of-joints solver for all 13 members in sequence.
  • All 13 Members: Results appear in four grouped sections (Top Chord, Bottom Chord, Verticals, Diagonals), color-coded: cyan = Compression, green = Tension, grey = Zero-force.
Corrected Truss Diagonals
Unlike some alternative truss layouts, the standard problem 4/22 utilizes diagonals AH, BG, DG, and EF. Because of this geometry, joint C has no diagonals, meaning the vertical member CG must carry the entire applied load L in compression.

§ 10 UI Design & Layout

Screen Layout

The application uses the same two-column layout as Problem 2/50:

  • Left panel (≈70%): An HTML5 <canvas> showing the truss with colored members, node dots, labelled nodes, load arrows, dimension lines, support symbols, reaction labels, and a legend.
  • Right panel (≈30%): Two input fields (spacing d and load L) plus a read-only info block describing support conditions.

Design Decisions
  • The truss diagram uses auto-scaling — the unitPx variable adapts so the truss always fits within available canvas space regardless of window size.
  • Result boxes are dynamically re-classed (e.g., ans-box compression) so their CSS color updates automatically on compute.
  • Steps are rendered as HTML strings with <span> color tags, supporting both numeric and symbolic output.
