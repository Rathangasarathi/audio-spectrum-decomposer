# Audio Spectrum Decomposer

## Objective

Allow users to:

1. Record audio
2. Visualize waveform
3. Generate spectrogram
4. Select a spectrogram region
5. Reconstruct selected audio
6. Export isolated audio

## MVP Features

### Recording

* Microphone recording

### Waveform

* Real-time waveform display

### Spectrogram

* STFT spectrogram

### Selection

* User-selectable region

### Reconstruction

* Inverse STFT

### Export

* WAV export

## Future Features

* AI source separation
* Sound classification
* Noise removal
* Wavelet analysis
* Live isolation
